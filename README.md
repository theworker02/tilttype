# tilttype

Tilt encode/decode helpers for type payloads in pipelines.

**Site:** https://theworker02.github.io/tilttype/

## Install / run

```bash
git clone https://github.com/theworker02/tilttype.git
cd tilttype
node src/cli.js
node --test
```
